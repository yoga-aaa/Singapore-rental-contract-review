## 本机启动

在仓库根目录打开终端，已有 .venv 时执行：

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py
```

打开 http://127.0.0.1:8501。离线模式不读取 .env，不发模型请求。内置示例和演示 PDF 都是合成材料。确认无个人资料，并核对提取文本后再点 Review。结果可能是三个完成标签，也可能是 model_needed（本地规则还不能判断，模型未运行）。没有结果不能冒充“已通过”。点击 Download report JSON 导出。

新电脑按 README 建环境、安装依赖、运行 bootstrap 下载固定参考版本。PDF 下载到本机，不随公开代码重新分发。若哈希变化，程序停止，不自动把新版参考与旧分数混用。

测试共发现 167 项。本机有旧索引时全部执行；干净副本仅跳过两项依赖历史 v13 私人旧索引的成绩复算，当前版本的 165 项执行并通过。跳过不是通过，也不表示用 v15 索引重新证明了 v13 的历史分数。演示 PDF 的 5/5 是功能自测，不是准确率或新泛化结果。

## 付费模式

默认关闭。只有另行授权后才在启动服务的终端设置 `$env:RENTAL_ENABLE_LIVE="1"`。把 OpenRouter key 放在根目录 .env，UI 还要求无个人资料确认和本次付费确认。每次选定文档评审预算最高 US$1，最多 40 次调用、200,000 tokens；未知用量或错误即停，无自动重试。每次按钮操作是一次新的评审预算，不是账户永久总预算。真实合同不在允许范围，PII 检测也不等于可靠脱敏。

## 演示顺序

1. 打开首页，说明主要用户是新加坡初次租房的国际学生群体，房型包括 HDB 和私人住宅。
2. 内置 HDB 风险示例，展示 review_required、实际出处、原文和询问问题。
3. 上传演示 PDF，展示提取预览和确认，说明不同模板仍需人检查分段。
4. 展示等义租金水电条款、证据不足条款和 model_needed 区别。
5. 输入虚构身份证号，展示拦截；不输入任何真实资料。
6. 下载 JSON，说明 cost 和 API calls；离线本次为零。
7. 展示 v16 原始失败与 v17 已曝光回归的改善，解释 precision、recall、unsafe 和引用实质支持率各自分母。不说“已实现95%外部引用支持率”，也不把两个同源测试说成两个独立外测。
